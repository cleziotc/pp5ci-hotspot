# N0CALL Hotspot v0.2.8

Release de estatísticas com escopo por reflector.

## Dashboard

- **Resumo de Hoje** passa a usar automaticamente o reflector atualmente conectado.
- O título mostra o reflector atual.
- Ao trocar para um reflector ainda não usado hoje, os valores aparecem em zero.
- Ao retornar a um reflector usado anteriormente no mesmo dia, os totais anteriores reaparecem.
- **Tempo de Uso (Airtime) · Hoje** usa o mesmo escopo do reflector atual.
- Nenhum histórico é apagado ao trocar de reflector.

## Statistics

- Novo seletor de escopo:
  - Todos os reflectores;
  - reflector específico;
  - atalho **Reflector atual**.
- O filtro se aplica a:
  - Hoje;
  - Últimos 7 dias;
  - Últimos 30 dias;
  - Horário de pico;
  - Duração média QSO;
  - Direção RF→NET / NET→RF;
  - Atividade das últimas 24 horas;
  - Top Stations;
  - Last Heard Estendido;
  - histórico de rede, quando houver amostras do reflector.

## Uso por Reflector

- Novo gráfico **Uso por Reflector · Últimos 30 Dias · Visão Geral**.
- Exibe QSOs e airtime por reflector.
- O gráfico permanece global mesmo quando outro filtro está ativo, para permitir comparação entre reflectores.

## API

- `/api/v1/statistics?reflector=...`
- `/api/v1/transmissions?reflector=...`
- `/api/v1/network/history?reflector=...`

## Segurança operacional

- Alteração somente de consulta, agregação e interface.
- Banco histórico permanece intacto.
- Nenhuma mudança na cadeia RF, MMDVMHost ou DStarGateway.
