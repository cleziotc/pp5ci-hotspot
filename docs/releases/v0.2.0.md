# N0CALL Hotspot v0.2.0

Camada web operacional sobre a base RF 0.1.0, mantendo MMDVMHost e DStarGateway como cadeia D-Star validada.

## Dashboard

- Estado real do modem, MMDVMHost, DStarGateway, RF e sistema.
- Tráfego D-Star em tempo real.
- RF→NET e NET→RF.
- Last Heard.
- BER e RSSI reais quando disponíveis.
- Slow text D-Star.
- Reflector atual por fonte autoritativa do DStarGateway.

## Statistics

- KPIs de hoje, 24 h, 7 d e 30 d.
- Airtime e número de QSOs.
- Gráficos de atividade.
- Top stations.
- Últimas transmissões.
- Enriquecimento por CSV.

## Settings

- Geral.
- MMDVMHost.
- DStarGateway.
- Hosts D-Star.
- Base de usuários CSV.
- Preferências do Dashboard.
- Aplicação administrativa controlada.
- Importação CSV grande com staging atômico.

## Diagnostics

- Saúde dos serviços.
- USB/serial e firmware.
- Portas UDP.
- Métricas RF.
- Recent Logs.
- Last Checks.
- Serial Check seguro.
- D-Star Path Check seguro, sem injeção de áudio RF.
- Last activity baseado na última transmissão real.

## Infraestrutura

- FastAPI.
- React/Vite.
- Mosquitto.
- Collector MQTT.
- SQLite/WAL.
- Nginx.
- systemd.
- Atualização diária de host files às 03:00 America/Sao_Paulo.
- CI para backend, frontend e shell.

## Correções importantes

- Fechamento explícito das conexões SQLite.
- RSSI D-Star reproduzível.
- Leitura correta do reflector.
- Localização CSV com cidade/estado.
- Recent Logs com auto-scroll inteligente.

- Consulta autenticada de repositório privado com token somente de leitura.
- Release notes reais.

- Extração segura do tarball.
- Backup transacional da camada web.

- Reinício apenas de API e collector.

- Health check de API, collector e cadeia RF.
- Restauração automática do estado anterior em caso de falha.
- Histórico local real.
- Rollback real com novo ponto de retorno antes da restauração.
