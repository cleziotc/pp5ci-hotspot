# N0CALL Hotspot v0.1.0

Primeira base D-Star validada e reproduzível do projeto.

## Destaques

- MMDVM_HS Dual Hat com firmware v1.5.2.
- Comunicação UART por CH340 em 115200 8N1.
- MMDVMHost congelado no commit validado.
- DStarGateway F4FXL v0.7.
- D-Star simplex módulo A.
- Serviços systemd persistentes.
- RX e TX RF validados.
- Slow data, BER e RSSI validados.
- Áudio AMBE validado.
- ECHO validado de ponta a ponta.
- Reinicialização completa da VM validada.
- Instalador preservando configurações existentes.

## Ambiente validado

- Ubuntu 26.04.1 LTS
- MMDVMHost: `590c531391dfd3146073afbc3956f70d42c62a46`
- DStarGateway: `0c1dbb5`
- Firmware: `MMDVM_HS_Dual_Hat-v1.5.2`, GitID `89daa20`

## Observação

Esta release é a referência de recuperação da cadeia RF antes da introdução da camada web 0.2.x.
