# PP5CI Hotspot v0.3.0

Primeira release da edição pública independente do PP5CI Hotspot.

## Destaques

### Repositório público

- Código e documentação passam a viver em `cleziotc/pp5ci-hotspot`.
- O projeto instalado não depende do repositório privado anterior.
- O updater consulta diretamente as releases públicas do PP5CI Hotspot.
- Não é necessário token GitHub para descobrir ou baixar atualizações.

### Instaladores completos

Foram criados dois pontos de entrada:

```text
install-vm.sh
install-rpi.sh
```

Ambos executam o provisionamento completo por `scripts/install-common.sh`.

#### VM Ubuntu/Debian

- MMDVM por porta serial/USB;
- descoberta inicial de `/dev/serial/by-id/`;
- confirmação manual do dispositivo.

#### Raspberry Pi

- MMDVM pela UART do GPIO;
- `/dev/serial0`;
- GPIO14/TXD no pino físico 8;
- GPIO15/RXD no pino físico 10;
- GND no pino físico 6;
- habilitação de `enable_uart=1`;
- remoção controlada do console serial;
- aviso de reboot quando a configuração de boot é alterada.

### Configuração inicial

O instalador solicita:

- indicativo do radioamador;
- frequência inicial;
- senha de administrador;
- confirmação da senha.

O indicativo é usado para configurar MMDVMHost, DStarGateway, DPlus e ircDDB/QuadNet.

Nenhum indicativo pessoal é embutido como configuração padrão.

### Senha administrativa

O token aleatório da linha privada foi substituído por senha definida pelo operador.

A senha:

- nunca é armazenada em texto claro;
- recebe salt aleatório;
- usa PBKDF2-HMAC-SHA256;
- usa 310.000 iterações;
- é comparada em tempo constante pelo backend.

O frontend não persiste a senha em localStorage ou sessionStorage.

### Atualização e rollback

O canal estável usa:

```text
https://github.com/cleziotc/pp5ci-hotspot/releases
```

Formato dos assets:

```text
pp5ci-hotspot-vX.Y.Z.tar.gz
pp5ci-hotspot-vX.Y.Z.tar.gz.sha256
```

O processo mantém:

- verificação SHA-256;
- extração segura;
- backup transacional;
- health check;
- restauração automática em falha;
- rollback com ponto de retorno;
- preservação do banco SQLite e configurações locais.

## Nota de migração

A v0.3.0 é a primeira linha oficialmente preparada para instalação a partir do repositório público. Instalações privadas anteriores não devem simplesmente trocar a URL do updater; use o instalador público em uma nova instalação ou faça uma migração planejada, pois paths, units e autenticação administrativa foram alterados.
