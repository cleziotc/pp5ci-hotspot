# N0CALL Hotspot v0.2.1

Atualização incremental da interface web sobre a base estável v0.2.0.

## About

- Página About totalmente atualizada para representar o estado real do projeto.
- Nova descrição do N0CALL Hotspot como appliance D-STAR para Linux.
- Arquitetura RF atualizada: rádio → MMDVM → MMDVMHost → DStarGateway → rede D-STAR.
- Fluxo da camada web documentado visualmente: MMDVMHost → MQTT → Collector → SQLite → FastAPI → Nginx/React.
- Componentes da solução atualizados para MMDVM, MMDVMHost, DStarGateway, Collector + Dados, API + Dashboard e Updates + Rollback.
- Tabela de versões validadas atualizada com N0CALL Hotspot v0.2.1.
- Operação transacional, proteção da cadeia RF, sincronização de hosts e persistência destacados.
- Diretórios e serviços atuais refletidos na interface.
- Campo “Próximos passos” removido.

## Segurança operacional

Esta release altera somente frontend e documentação do produto. O updater continua reiniciando apenas API e collector durante a aplicação; MMDVMHost e DStarGateway são preservados e verificados no health check.

Configurações em `/etc/pp5ci-hotspot` e dados operacionais em `/var/lib/pp5ci-hotspot` permanecem preservados.
